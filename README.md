# Speaker Cleaner Hub

Free speaker cleaner tools and guides for iPhone and Android phones. Clean your phone speaker with sound — no app download needed.

Live site: https://speakercleanerhub.github.io/

## What is on this site

- **Speaker Cleaner tool** — plays low-frequency vibration tones (165 Hz), a frequency sweep (100 Hz to 20 kHz) and noise bursts to help remove dust and water from phone speakers. Built with the Web Audio API.
- **Volume Test** — plays real test tones at 25%, 50%, 75% and 100% volume.
- **Frequency Generator** — plays a real sine tone at any frequency from 20 Hz to 20,000 Hz.
- **Sound Test** — left/right channel, stereo, bass and treble test tones.
- **20 guides** — practical, original guides on cleaning and testing phone speakers.

## Technical notes

- Pure static HTML/CSS/JavaScript. No frameworks, no external CSS, JS or fonts.
- All tools use the Web Audio API (OscillatorNode, GainNode, StereoPannerNode) and generate real sound in the browser. No fake numbers.
- Responsive, mobile-first design.
- No ads.txt on this site.
